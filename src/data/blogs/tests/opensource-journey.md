## 起点

每个人的开源之旅都有一个起点。对我来说，那是在大学期间第一次给一个 Vue 组件库提 PR 的经历。

## 第一次贡献

那时候我还不太熟悉 Git 的工作流，一个简单的文档修正花了我整整一个下午。但当 PR 被合并的那一刻，那种成就感是无与伦比的。

## 维护项目

后来我开始了自己的开源项目：

- **MVideo** — 一个现代化 Web 视频播放器
- **Ocean Book** — 一个 Astro 博客主题
- **ai** — 一个隐私 AI 项目

## 收获

开源带给我的远不止代码：

1. **技术成长** — Code Review 是最好的学习方式
2. **社区连接** — 遇到了很多志同道合的开发者
3. **影响力** — 你的代码可以被全世界的人使用

## 给新手的建议

> 不要害怕你的第一个 PR，哪怕只是修一个错别字。

开源的世界欢迎每一个人。
